# AI Tele Caller

An AI-powered tele-calling simulation system designed to automate customer interactions, improve engagement, and generate actionable insights.

## Features
- Campaign setup interface
- Real-time AI call simulation
- Intelligent conversation handling
- Customer sentiment and intent analysis
- Analytics dashboard

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- AI: OpenAI API (simulated)

## Use Case
Helps businesses automate tele-calling while reducing manpower and increasing efficiency.
